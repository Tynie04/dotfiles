# hosts/hermes2

Configuration for hermes2, a personal laptop running NixOS with Hyprland.

```
hermes2/
├── default.nix               imports all system modules, host-specific settings
├── hardware-configuration.nix  generated by nixos-generate-config, not portable
└── home.nix                  Home Manager overrides specific to this machine
```

## default.nix

Imports all modules from `system/` and sets things that are specific to this machine:

* hostname
* environment variables (cursor theme, terminal, NH_FLAKE path)
* uinput kernel module and udev rule for controller support
* polkit authentication agent as a systemd user service
* SSH server with password authentication disabled

## hardware-configuration.nix

Generated by `nixos-generate-config` during NixOS installation. Describes the actual hardware:
filesystems, boot initrd modules, CPU microcode. Do not edit this manually.

> [!NOTE]
> This file is machine-specific and will be different on every machine. It is committed here
> because this is the only machine using this host config. If you reinstall NixOS, regenerate
> it with `nixos-generate-config` and copy the result here.

## home.nix

Host-specific Home Manager config. Currently manages the hyprpaper config because it needs
the actual monitor name (`eDP-1`), which is hardware-specific and not portable.

If you add a second monitor, add another `wallpaper { }` block with the correct monitor name.
Run `hyprctl monitors` to see all connected outputs and their names.
