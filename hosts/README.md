# hosts

One directory per machine. Each host directory is the entry point for its NixOS configuration
and is referenced by name in `flake.nix` under `nixosConfigurations`.

```
hosts/
└── hermes2/
    ├── default.nix               imports all system modules and defines host-specific settings
    ├── hardware-configuration.nix  generated by nixos-generate-config, machine-specific
    └── home.nix                  host-specific Home Manager overrides (monitor names, etc.)
```

## Adding a new machine

### 1. Create a directory for the new host

```bash
mkdir ~/dotfiles/hosts/<hostname>
```

### 2. Generate hardware configuration

On the new machine after installing NixOS, copy the generated hardware config:

```bash
cp /etc/nixos/hardware-configuration.nix ~/dotfiles/hosts/<hostname>/hardware-configuration.nix
```

### 3. Create default.nix

Copy `hosts/hermes2/default.nix` as a starting point and adjust:

* `networking.hostName` to the new hostname
* `environment.variables` if needed
* Remove or add system modules that do not apply to this machine

### 4. Create home.nix

Copy `hosts/hermes2/home.nix` and update monitor names. Run `hyprctl monitors` on the new
machine to find the correct output name to use in the hyprpaper config.

### 5. Register the host in flake.nix

Add a new entry under `nixosConfigurations` in `flake.nix`:

```nix
nixosConfigurations.<hostname> = nixpkgs.lib.nixosSystem {
  specialArgs = { inherit inputs self; };
  modules = [
    ./hosts/<hostname>
    {
      home-manager = {
        users.tijnw.imports = [ ./home ./hosts/<hostname>/home.nix ];
        extraSpecialArgs = { inherit inputs self; };
      };
    }
  ];
};
```

### 6. Rebuild on the new machine

```bash
git add hosts/<hostname>/
nh os switch ~/dotfiles
```
